Step sequencing

Click or drag to enter steps. Velocity, probability, MIDI note length, and many other parameters can be editer quickly with mouse or midi controller.

Every track keeps its own parameters; global controls to set everything at once. Battle-tested and well-thought controls for easy performance and maximum flow state.

Euclidean rhythms and polyrhythms

Create mind-bending rhythms with Generative parameters - set a pattern length, pulse count. Rotate hits position, or use Permute to reorder them.

TEMPORAL ARRAY supports any length, polyrhythm, and time signature, and can be a great tool for experiments and performance.

Procedural fills

Procedural fill controls with 4 algorithms. XY pad for fill controls and auto-fill functions.

Also, you can put your fills in pattern slots and trigger them with momentary midi buttons.

Flexible MIDI

  • MIDI output: assign a drum note per track and an output channel. Send step velocities and note lengths to other instruments, or disable the sampler entirely in MIDI-only mode.
  • Parameter control: use host automation and host MIDI learn for exposed parameters. Set parameter ranges to limit the travel of mapped controls.
  • Performance controls: trigger temporary patterns with MIDI notes or CCs; release to return. Assign a CC to fill density for continuous control.
  • Pad grids: edit steps from a compatible CC-based controller and send step and playhead states back to its lights. Configure grid dimensions, track rows and state values.

High performance sampler

Load a sample per track, or several, and one is picked at random on each hit. Control volume, pitch, playback speed, store settings in sound banks and switch between them instantly.

The sampling engine is optimized for maximum performance, and you could load many of these plugins or many tracks.

Two ways to see your pattern

Work in the step grid or switch to the concentric Circle view.
